🔀 Distributed Transaction Journey (Order Placement & Saga Execution)
Visual Microservices Lifecycle & Live Synchronized Telemetry Pipeline
IDLE / ARCHITECTURAL STANDBY
This interactive pipeline visualizes the complete end-to-end distributed lifecycle for incoming e-commerce requests across the microservices ecosystem. When you trigger any preset below or dispatch a custom payload, the journey nodes dynamically synchronize with real cluster state.
STEP 1 • PORT 8080 STANDBY
1️⃣ Gateway & OAuth2
API Gateway & Keycloak
Validates client JWT, enforces Token-Bucket rate limiting, injects X-Correlation-ID, and proxies to Order Service.
➔
STEP 2 • PORT 8081 STANDBY
2️⃣ ACID Outbox Write
Order Service & PostgreSQL
Persists Order in PostgreSQL write model and inserts OutboxEvent in single ACID transaction. Relays to Kafka & SQS.
➔
STEP 3 • PORT 8082 STANDBY
3️⃣ Inventory Mutex Lock
Inventory Service & Redis
Consumes event on Virtual Thread, acquires Redis distributed lock SET NX PX, checks available stock, and emits inventory event.
➔
STEP 4 • PORT 8084 STANDBY
4️⃣ Payment Authorization
Payment Service (Idempotent)
Executes simulated payment with idempotency key. Emits PaymentCaptured or declines (>$1000) triggering compensating rollback.
➔
STEP 5 • PORT 8083 STANDBY
5️⃣ Saga Archival & S3
OrderSaga & Notification
Orchestrator marks order CONFIRMED. Notification Service generates PDF invoice and archives it to LocalStack S3 bucket.
🟢 1. Happy Path E-Commerce Flow
ACID + SAGA
Creates order ($149.00), reserves stock with Redis mutex lock, captures payment, confirms order, and stores invoice in AWS LocalStack S3.
curl -X POST "http://localhost:8081/api/orders" \ -H "Content-Type: application/json" \ -H "X-Correlation-ID: corr-live-happy" \ -d '{"customerId":"cust-live-01","items":[{"productId":"PROD-TECH-001","quantity":1,"unitPrice":149.00}]}'
🔴 2. Payment Decline & Saga Rollback
COMPENSATION
Submits order ($5000.00), card exceeds limit (402), Kafka event triggers compensating transaction: order cancelled and reserved stock restored in Redis.
curl -X POST "http://localhost:8081/api/orders" \ -H "Content-Type: application/json" \ -H "X-Correlation-ID: corr-live-decline" \ -d '{"customerId":"cust-decline-01","items":[{"productId":"PROD-TECH-001","quantity":1,"unitPrice":5000.00}]}'
🟠 3. Inventory Exhaustion Test
GUARD FAIL
Orders 999 units of PROD-TECH-001 exceeding warehouse stock. Evaluates inventory guard and fast-fail boundary before payment invocation.
curl -X POST "http://localhost:8081/api/orders" \ -H "Content-Type: application/json" \ -H "X-Correlation-ID: corr-live-exhaust" \ -d '{"customerId":"cust-overstock","items":[{"productId":"PROD-TECH-001","quantity":999,"unitPrice":149.00}]}'
🔵 4. Customer Order Cancellation
ROLLBACK
Submits POST /api/orders/{id}/cancel on an existing order. Emits OrderCancelledEvent to Kafka, releasing reserved inventory stock.
curl -X POST "http://localhost:8081/api/orders/<orderId>/cancel" \ -H "Content-Type: application/json" \ -H "X-Correlation-ID: corr-live-cancel" \ -d '{"reason":"Customer requested cancellation from Control Center"}'

            🛠️ Local Developer CLI Cheatsheet (Testing with LocalStack)
          

        

        

          You can interact with LocalStack using standard AWS CLI, AWS SDKs, or curl without real AWS credentials or charges:
        

        

          
# 1. Configure dummy test credentials

          
export AWS_ACCESS_KEY_ID=test && export AWS_SECRET_ACCESS_KEY=test && export AWS_DEFAULT_REGION=us-east-1

          
# 2. Interact with S3 Invoices bucket

          
aws --endpoint-url=http://localhost:4566 s3 ls

          
aws --endpoint-url=http://localhost:4566 s3 mb s3://ecommerce-invoices

          
# 3. Inspect SQS Saga Queues

          
aws --endpoint-url=http://localhost:4566 sqs list-queues

          
# 4. Check DynamoDB Tables

          
aws --endpoint-url=http://localhost:4566 dynamodb list-tables
